# Агрегатор внешних геофизических данных

## Проблема
Исследователям нужны измерения из разных внешних источников, которые отличаются форматами и обозначениями пропусков. Сервис получает данные по запросу, приводит их к общему виду, проверяет качество и позволяет скачать для дальнейшего анализа.

## Для кого
Пользователи - исследователи и аналитики геофизических данных.

## Что входит
- Выбор источника, станции, измеряемых компонент и периода.
- Подключение не меньше двух внешних источников через отдельные модули. Конкретные источники ещё предстоит выбрать и проверить.
- Создание задания на сбор данных и просмотр его состояния. Одно задание получает данные из одного источника.
- Приведение времени и обозначений пропусков к единому формату.
- Сохранение сведений об источнике, станции, компонентах и единицах измерения.
- Проверка структуры данных, повторяющихся записей и пропусков.
- Формирование отчёта о качестве и полноте полученных данных.
- Хранение результатов и истории заданий.
- Выгрузка данных и отчёта в CSV/JSON через API.
- Понятные сообщения об ошибках запроса, недоступности источника или неверном ответе.

## Что не входит
- Обучение нейросетей, автоматическое восстановление пропусков и прогнозирование.
- Карта, трёхмерная визуализация и преобразование географических координат.
- Собственная регистрация пользователей и разграничение прав доступа.
- Автоматическое удаление необычных измерений: такое значение может быть важным наблюдением.
- Объединение данных разных станций, компонент или несовместимых единиц измерения без явно заданных правил.
